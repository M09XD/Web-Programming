CSE 4165 Web Programming - Past Final Solutions (Fall 2023 to Spring 2026)

Contains all 25 question groups in separate semester/question folders. Use the folder names to find the question.

STYLE
- Beginner lab style; no frameworks or advanced architecture.
- HTML + JavaScript tasks use index.html and script.js.
- PHP questions use q1.php/q2.php/q3.php as needed.
- Database questions include setup.sql and PHP code.

RUNNING
1. Install XAMPP and start Apache + MySQL.
2. Copy a semester folder under C:\xampp\htdocs\.
3. For a database question, import its setup.sql using phpMyAdmin.
4. Browse to the PHP file through http://localhost/... .
5. Re-import setup.sql before each fresh run because UPDATE queries change the stored rows.

LIMITS
- PHP files were syntax-checked with PHP 8.4.
- JavaScript files were syntax-checked with Node.js.
- This environment did not include a running MySQL/MariaDB server, so database queries were not run end-to-end here.
- Comments identify source-paper contradictions and whether the solution follows the sample output or the written rule.
- Lab 8 ZIP was not supplied; available style examples were from Lab 6, 7, 9, 10 and 11.
