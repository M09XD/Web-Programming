Most papers are two hours and 30 marks (three groups of 10). Summer 2024 is the exception: 40 marks and four groups of 10. Seven of the eight papers have a JavaScript question. Every paper contains a database question.

0.2 Six recurring question families
A. JavaScript stateful tracker/game: persistent variables outside functions, running total/counter, range feedback, and a late warning rule. Examples: guessing game, password score, calories, study hours.
B. JavaScript one-shot calculator/string check: read values, convert/check, calculate, output to a label or alert. Examples: palindrome, BMI, electricity bill.
C. PHP whole-unit / leftover / waste function: calculate whole venues/screens/pizzas with ceil(), calculate unused capacity, then waste.
D. PHP classify-and-compare: multiply two values, classify with an if/elseif ladder, and compare total against target.
E. PHP loop/string logic: nested for loops, digit arithmetic with %, password checks with strlen()/substr()/preg_match().
F. PHP + MySQL reports and updates: create a dataset, make a table, insert given rows, SELECT/report, UPDATE rules, and grouped output. Recent versions have four tasks.

0.3 Typical structure
The most common recent layout is Q1 programming, Q2 PHP and Q3 PHP/MySQL, 10 marks each. Summer 2024 adds a second PHP task and a fourth database task. Fall 2025 is the only supplied paper without JavaScript; its first two questions are PHP.

0.4 SQL four-task skeleton
1. SELECT and summarize the initial data (COUNT, SUM, AVG, sometimes GROUP BY/HAVING).
2. UPDATE rows matching a condition.
3. UPDATE a bonus/percentage, often with a cap on the new value.
4. SELECT a grouped report, often ORDER BY ... DESC.
Always read the paper’s exact order and conditions. Output for Task 1 is usually best captured before updates; later reports should reflect the updates already executed.

0.5 Forecast (not a guarantee)
- JavaScript: a stateful tracker with a global counter, range messages and an after-N warning is a strong candidate. Still practise a one-shot calculator and string check.
- PHP: classify-and-compare or the ceil/leftover/waste calculation is worth high priority. Also practise loops/digits and password rules.
- SQL: practise full database setup, SELECT, GROUP BY, conditional UPDATE, ORDER BY DESC, HAVING and “only if the result is at most X”.

PART 5. SEVEN CORE LESSONS WITH DIAGRAMS

Lesson 1 - JavaScript state persists only when declared outside the click function.

Page loads:
    let total = 0; let count = 0;
        |
        v
Click 1: total = total + value1; count = count + 1
        |
        v
Click 2: total = previous total + value2; count = count + 1

If total and count are declared inside the function, they reset every click. Trackers require global variables.

Lesson 2 - JS button/input/output pattern.

HTML input id="hours" -> button onclick="addStudy()" -> JS reads .value
                                               -> Number(...)
                                               -> calculate / if-else
                                               -> output element .innerText

Lesson 3 - PHP form request pattern.

First visit (GET) -> page displays the HTML form -> isset($_POST["btn"]) is false
Click Submit (POST) -> PHP reads $_POST fields -> casts values -> calculates -> echo result

Remember: JavaScript identifies an input/output with id. PHP receives a form field by name.

Lesson 4 - SQL clause order.

SELECT columns / aggregates
FROM table
WHERE row_condition
GROUP BY group_column
HAVING aggregate_condition
ORDER BY sort_column DESC
LIMIT n;

WHERE filters individual rows before grouping. HAVING filters groups after aggregation.

Lesson 5 - Ceiling and waste.

needed = people * units_per_person
units = ceil(needed / capacity)
leftover = units * capacity - needed
waste = leftover * cost_per_seat_or_slice

Example: 10 students * 3 slices = 30 slices. Each pizza holds 8. ceil(30/8)=4 pizzas; capacity=32; leftover=2. At 1050 BDT per pizza, cost per slice=1050/8=131.25; waste=2*131.25=262.50 BDT.

Lesson 6 - Best two CT marks.

best_two_average = (ct1 + ct2 + ct3 - min(ct1,ct2,ct3)) / 2
Example: CT marks 8, 12, 15 -> (8+12+15-8)/2 = 13.5.

Lesson 7 - Round-trip average speed.

If the distance up and down is the same:
    distance = uphill_speed * uphill_time
    downhill_time = distance / downhill_speed
    average_speed = (2 * distance) / (uphill_time + downhill_time)
Do not use the ordinary arithmetic mean (up_speed + down_speed)/2 when the two travel times differ.

LAST-MINUTE TRAPS
- Inputs are strings until converted to numbers.
- Keep running totals and counters outside JS functions.
- The later warning rule may override the ordinary feedback; apply it after the normal if/else ladder.
- Use ceil(), not round(), when complete units must be booked.
- Use WHERE for rows and HAVING for groups.
- If a cap refers to the final value, test the expression for the new value in WHERE.
- Use different IDs for different HTML buttons; the Lab 11 sample has a duplicate id bug.
- Use isset($_POST["btn"]) before reading PHP form values.
- Use SQL aliases (AS total, AS avg_rating) and then read those aliases in PHP.
- Re-import setup.sql before every fresh test because UPDATE statements change the data.
- Do not execute UPDATE statements before a report that must reflect the original dataset.

function check() {
    let text = document.getElementById("text").value.toLowerCase();
    let isPal = true;

    for (let i = 0; i < text.length / 2; i++) {
        if (text.charAt(i) != text.charAt(text.length - 1 - i)) {
            isPal = false;
        }
    }

    if (isPal) {
        document.getElementById("ans").innerText = "Yes. It is a Palindrome.";
    } else {
        document.getElementById("ans").innerText = "No. It is not a Palindrome.";
    }
}

function calc() {
    let location = document.getElementById("location").value;
    let urban = document.getElementById("urban").checked;
    let rural = document.getElementById("rural").checked;
    let raw = document.getElementById("units").value;
    let units = Number(raw);

    if (location == "") {
        alert("Select a location.");
        return;
    }
    if (!urban && !rural) {
        alert("Choose Urban or Rural.");
        return;
    }
    if (raw == "" || isNaN(units) || units <= 0) {
        alert("Unit Consumed must be a positive number.");
        return;
    }

    let rate;
    if (location == "Dhaka") {
        rate = urban ? 7.5 : 6.5;
    } else if (location == "Chattogram") {
        rate = urban ? 7.0 : 6.0;
    } else {
        rate = urban ? 6.5 : 5.5;
    }

    let bill = units * rate;
    let surcharge = 0;
    if (bill > 1000) {
        surcharge = bill * 0.10;
    } else if (bill >= 500) {
        surcharge = bill * 0.05;
    }

    alert("Final bill: " + (bill + surcharge).toFixed(2) + " taka");
}

<?php
function calculate($minutes, $up, $down) {
    $hoursUp = $minutes / 60;
    $distance = $up * $hoursUp;
    $hoursDown = $distance / $down;
    $average = (2 * $distance) / ($hoursUp + $hoursDown);
    return (int)round($average);
}

echo calculate(18, 20, 60) . "<br>";  // 30
echo calculate(30, 8, 24);              // 12

let secret = Math.floor(Math.random() * (5000 - 500 + 1)) + 500;
let count = 0;

function numberGuess() {
    count++;
    let guess = Number(document.getElementById("guess").value);
    let ans = document.getElementById("ans");

    if (guess == secret) {
        ans.innerText = "Correct!";
        document.getElementById("guess").disabled = true;
        document.getElementById("submitBtn").disabled = true;
    } else {
        if (guess > secret) {
            ans.innerText = "Too high!";
        } else {
            ans.innerText = "Too low!";
        }

        if (count >= 5) {
            ans.innerText += " Out of guesses!";
            document.getElementById("guess").disabled = true;
            document.getElementById("submitBtn").disabled = true;
        }
    }
}

function resetGame() {
    secret = Math.floor(Math.random() * (5000 - 500 + 1)) + 500;
    count = 0;
    document.getElementById("guess").disabled = false;
    document.getElementById("submitBtn").disabled = false;
    document.getElementById("guess").value = "";
    document.getElementById("ans").innerText = "";
}

let attempts = 0;

function checkStrength() {
    attempts++;
    let password = document.getElementById("password").value;
    let score = 0;

    if (password.length >= 6) {
        score += Math.floor((password.length - 6) / 2) * 10;
        if (/[A-Z]/.test(password)) { score += 15; }
        if (/[a-z]/.test(password)) { score += 15; }
        if (/[0-9]/.test(password)) { score += 20; }
        if (/[!@#$%^&*]/.test(password)) { score += 25; }
    }

    let level;
    if (score >= 100) { level = "Perfect Password! Success!"; }
    else if (score >= 91) { level = "Very Strong"; }
    else if (score >= 71) { level = "Strong"; }
    else if (score >= 51) { level = "Medium"; }
    else if (score >= 31) { level = "Weak"; }
    else { level = "Very Weak"; }

    if (attempts > 8 && score < 71) {
        level += "\nNeed practice! Use 10+ characters with upper, lower, digits and !@#$%^&*";
    }

    document.getElementById("label").innerText =
        level + "\nScore: " + score + "\nAttempt: " + attempts;
}

<form method="post">
    Attendees: <input type="number" name="people"><br>
    Cost per person: <input type="number" name="cost"><br>
    Venue capacity: <input type="number" name="cap"><br>
    <button name="btn">Calculate</button>
</form>
<?php
function calculate($people, $cost, $cap) {
    if ($cap <= 0) {
        echo "Venue capacity must be greater than zero.";
        return;
    }
    $venues = ceil($people / $cap);
    $empty = $venues * $cap - $people;
    $wasted = $empty * $cost;

    echo "Total Venues: $venues<br>Empty Seats: $empty<br>";
    echo "Wasted Money (BDT): " . number_format($wasted, 2);
    // The paper also mentions a fixed 15,000 BDT venue cost, but the sample outputs
    // use empty seats * cost per person. This solution follows the sample outputs.
}
if (isset($_POST["btn"])) {
    calculate((int)$_POST["people"], (int)$_POST["cost"], (int)$_POST["cap"]);
}
?>

let goal = 2000;
let total = 0;
let entries = 0;

function addCalories() {
    let cal = Number(document.getElementById("cal").value);
    total += cal;
    entries++;

    let feedback;
    if (total <= 800) { feedback = "You're off to a healthy start!"; }
    else if (total <= 1600) { feedback = "Good progress, keep it balanced!"; }
    else if (total < goal) { feedback = "Almost at your limit!"; }
    else { feedback = "Goal reached! Stay mindful!"; }

    if (entries > 10 && total < goal) {
        feedback = "Be cautious of frequent snacking!";
    }

    document.getElementById("out").innerText =
        "Total: " + total + " / " + goal + " (" + (total / goal * 100).toFixed(1) + "%)\n" +
        "Entries: " + entries + "\n" + feedback;
}

let goal = 20;
let totalHours = 0;
let sessions = 0;
let subjects = [];

function addStudy() {
    let subject = document.getElementById("subject").value;
    let hours = Number(document.getElementById("hours").value);

    totalHours += hours;
    sessions++;
    subjects.push(subject);
    let average = totalHours / sessions;

    let feedback;
    if (totalHours <= 5) { feedback = "Start studying regularly!"; }
    else if (totalHours <= 12) { feedback = "Good progress!"; }
    else if (totalHours < goal) { feedback = "Almost ready!"; }
    else { feedback = "Weekly goal reached!"; }

    if (sessions > 7 && totalHours < goal) {
        feedback = "Increase your study time!";
    }

    document.getElementById("out").innerText =
        "Total: " + totalHours + " hours, Average: " + average +
        " hours, Subjects: [" + subjects.join(", ") + "], " + feedback;
}

CREATE DATABASE IF NOT EXISTS tourism;
USE tourism;
DROP TABLE IF EXISTS tourist_spot;
CREATE TABLE tourist_spot (
    SpotID INT PRIMARY KEY,
    SpotName VARCHAR(50) NOT NULL,
    Region VARCHAR(10) NOT NULL,
    Category VARCHAR(30) NOT NULL,
    Rating DECIMAL(3,1) NOT NULL,
    EntryFee DECIMAL(10,2) NOT NULL,
    VisitorsPerYear INT NOT NULL
);
INSERT INTO tourist_spot VALUES

(2,'Sundarbans Forest','KHL','Nature',4.3,150,80000),
(3,'Ratargul Forest','SYL','Nature',4.8,100,60000),
(4,'Kuakata Beach','PTU','Beach',4.5,0,90000),
(5,'Shat Gambuj Mosque','BGH','Heritage',4.7,30,70000),
(6,'Paharpur','NWG','Heritage',4.1,30,40000);

--- FILE: q3.php ---
<?php
$conn = new mysqli("localhost", "root", "", "tourism");
if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
}

echo "<h3>1. Selected tourist spots</h3>";
$res = $conn->query("SELECT SpotName, Region, Rating FROM tourist_spot
                     WHERE Rating > 4.5 OR SpotName LIKE '%Beach%'
                     ORDER BY Rating DESC");
while ($row = $res->fetch_assoc()) {
    echo $row["SpotName"] . " | " . $row["Region"] . " | " . $row["Rating"] . "<br>";
}

$conn->query("UPDATE tourist_spot
              SET Rating = Rating + 0.2, EntryFee = EntryFee * 1.10
              WHERE Rating BETWEEN 4.0 AND 4.5 AND EntryFee > 0");
echo "<p>2. Updates completed.</p>";

echo "<h3>3. Statistics by category</h3>";
$res = $conn->query("SELECT Category, COUNT(*) AS spots, AVG(Rating) AS avg_rating,
                            SUM(VisitorsPerYear) AS visitors
                     FROM tourist_spot GROUP BY Category
                     HAVING AVG(Rating) > 4.4 ORDER BY avg_rating DESC");
while ($row = $res->fetch_assoc()) {
    echo $row["Category"] . " | " . $row["spots"] . " | " . $row["avg_rating"] .
         " | " . $row["visitors"] . "<br>";
}

echo "<h3>4. Estimated yearly revenue by region</h3>";
$res = $conn->query("SELECT Region, SUM(EntryFee * VisitorsPerYear) AS revenue
                     FROM tourist_spot GROUP BY Region
                     HAVING SUM(EntryFee * VisitorsPerYear) > 1000000
                     ORDER BY revenue DESC");
while ($row = $res->fetch_assoc()) {
    echo $row["Region"] . " | " . number_format($row["revenue"], 2) . "<br>";
}
$conn->close();
?>
