## Overview

This repository is a curated collection of web programming resources built for university coursework and exam preparation. It includes:

- HTML, CSS, and JavaScript exercises
- PHP and MySQL implementations
- Midterm and final exam question sets
- Worked solutions and study guides
- Cheat sheets and revision notes
- Course-focused practice materials for UIU students

The goal is to make learning practical, organized, and easy to revisit whenever you need to revise a topic or prepare for an assessment.

> This is primarily a study and resource repository, not a single production web app. Most files are standalone exercises and should be opened or run according to their individual requirements.

## Why This Repository?

Web development is best learned by writing code, solving problems, and practicing patterns repeatedly. This repository brings together structured lab work and exam-oriented questions so students can:

- revise core concepts quickly
- inspect complete solutions to real exam questions
- practice front-end and back-end skills in context
- prepare for midterm and final assessments more effectively

## Getting Started

### Clone the repository

```bash
git clone https://github.com/M09XD/Web-Programming.git
cd Web-Programming
```

### Requirements

- A modern browser
- A text editor or IDE such as VS Code
- XAMPP / WAMP / MAMP for PHP and MySQL examples
- Local PHP server support for runtime execution

## Running the Projects

### HTML / CSS / JavaScript

Most front-end examples can be opened directly in a browser:

1. Open the folder containing the exercise.
2. Find the HTML file.
3. Open it in your browser.

If the project uses modules or browser restrictions, use a local server instead of opening files directly from the filesystem.

### PHP Applications

Many PHP exercises require a local server environment:

```bash
# Example for XAMPP on Windows
C:\xampp\htdocs\
```

Then access the file via localhost, for example:

```text
http://localhost/<folder-name>/<file>.php
```

### MySQL / Database Tasks

If a lab or question includes a database setup script:

1. Start Apache and MySQL in XAMPP
2. Import the SQL file via phpMyAdmin
3. Update the database credentials if required
4. Run the PHP script through your local server

## Study Workflow

A good way to use this repository is:

1. Read the lab description or question statement
2. Open the relevant source file
3. Understand the logic and structure
4. Try to solve it yourself before checking the solution
5. Compare your implementation with the provided example code
6. Repeat similar exercises to reinforce understanding
